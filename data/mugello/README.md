# Registro de Mugello

**Atribución:** INGV (Istituto Nazionale di Geofisica e Vulcanologia),
*Italian National Seismic Network*, red IV, DOI
[10.13127/SD/X0FXNH7QFY](https://doi.org/10.13127/SD/X0FXNH7QFY).
Consulta la [ficha de red](https://www.fdsn.org/networks/detail/IV/) y la
[política de datos EIDA Italia](https://eida.ingv.it/en/datapolicy), que
documenta la atribución y la aplicación habitual de CC BY 4.0 cuando no se
especifica una licencia particular.

`original.mseed` conserva la respuesta archivada del servicio FDSN.
`trimmed.mseed` contiene el recorte temporal, sin filtrado, interpolación,
remuestreo ni corrección de respuesta. Los archivos conservan el canal
`IV.FNVD..HHZ`, muestreado a 100 Hz. Las marcas manuales P y S se tomaron
del servicio de eventos INGV para el evento 23558121. La figura y el
resultado de ejemplo fueron elaborados a partir de ese recorte.

[case.json](case.json) especifica la consulta original, hashes SHA-256,
tiempos de recorte, marcas y umbrales de la demo. La licencia aplicable
a los datos del proveedor no es una licencia del código del proyecto.
